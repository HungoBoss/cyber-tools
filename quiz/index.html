How to play

  1. Choose a category and point value. The question appears in large text, with all four team scores below.
  2. Use your physical buttons and timer. The presenter selects the responding team and judges the answer.
  3. Correct answer: add the question’s value, from +100 to +500 points. The question is marked complete.
  4. Wrong answer or buzzing without an answer: deduct 33% of the question’s value: −33, −66, −99, −132 or −165 points. Negative scores are allowed. One other team may steal. A second wrong answer finishes the question.
  5. No team buzzes: finish the question with no score change. Passing before buzzing is free. After buzzing, a wrong answer or no answer by the deadline incurs the 33% penalty.
  6. After buzzing ends, click Show answer to display the correct answer to everyone. The question stays open after scoring. Hide answer conceals it again; Board returns to the board. Showing an answer does not change scores.
  7. Use the score controls to add or deduct extra points. Undo reverses the last action. Returning to the board keeps an unfinished question active.
  8. Edit game contains Start Set A and Start Set B, each with 25 built-in questions. Starting a set resets scores and progress and keeps saved team names. You can also edit teams, categories, questions and answers. Export backup saves progress. Restart round keeps your current set and edits while clearing scores and answered questions. Reset game restores Set A, the built-in questions, default team names and zero scores.
